# Stride VR Localizer

**Набор инструментов для локализации UI VR-приложений на движке Xenko/Stride.**

Создан при локализации [Virtual Desktop](https://www.vrdesktop.net/) для
гарнитуры PICO 4 — китайский язык, 187 строк UI и атлас шрифта, пересобранный
с нуля. Весь обратный инжиниринг и все подводные камни описаны здесь, чтобы
любой человек мог повторить это для своего языка, своего приложения или и
того и другого.

```
PICO 4 (Android 10, root)
  Virtual Desktop 1.34.22.0  —  Stride (Xenko) 3.2.0.2, .NET NativeAOT
  2120 сериализованных объектов в двух файлах .bundle · 8 UI-страниц · 8 шрифтов
```

## Что делает инструмент

Переписываются два типа объектов внутри APK:

| | было | стало |
|---|---|---|
| строки UI в 8 объектах `UIPage` | английский | 187 переводов |
| 3 объекта шрифтов | 224 глифа, атлас 256×212 | 621 глиф, атлас 256×1235 |

Шрифты пересобираются так: новые глифы растеризуются из предоставленного
вами TTF и укладываются **ниже исходного атласа**. Ни один байт исходных
пикселей не двигается, поэтому сломать то, что уже работало, невозможно.

## Три находки, которые всё решили

**1. В APK два bundle — и движок читает маленький.**

```
default.b65fc36561f156d9d380862e7304cc55.bundle   1 GB    данные
default.bundle                                    224 KB  индекс
```

В файле индекса лежит **вторая полная копия таблицы из 2120 записей об
объектах**. Движок ищет объекты именно через неё. Если править только большой
bundle, приложение умирает через 15 секунд после запуска с
`NullReferenceException` в шрифтовой подсистеме и `SIGSEGV`. Каждая неудачная
сборка в истории этого проекта в итоге сводилась к этому одному факту.
`bundle_writer.py` синхронизирует обе таблицы и проверяет их совпадение до
начала записи.

**2. Длина строк UIPage может быть любой. Точность — нет.**

Заменяйте весь шаблон `varint(длина) + текст` — и длину можно менять как
угодно. Но если сделать простой `bytes.replace("Environment", "环境")`, вы
заодно перепишете `itemEnvironment`, `btnSettings` и
`UI/ControlPanel/EnvironmentSheet` — поиск контрола сломается и процесс
упадёт. (На раннем этапе проекта был сделан вывод «нужна равная длина»; он
оказался неверным, и в документации сохранено полное опровержение с
доказательствами.)

Режим `--mode strict-field` добавляет второй, так же привязанный к префиксу
длины проход для меток, за pad-рованных внутри своего поля; на референсной
сборке он дал те же 40 строк, что и обычный strict, потому что все остатки там
оказались подстроками имён контролов.

**3. Записи словаря шрифта имеют переменную длину, и счётчик лежит не по
фиксированному смещению.**

Ключ — это `UTF-8(кодовая точка) + 0x00`, поэтому фиксированный шаг 38 байт
рассинхронизируется сразу после U+007F. Парсер вместо этого находит словарь по
якорю — символу пробела.

Полные разборы: [формат bundle](docs/02-bundle-format.md),
[формат шрифта](docs/03-font-format.md),
[замена строк](docs/05-string-patching.md) и
[подводные камни](docs/07-pitfalls.md) — страницу про грабли читайте первой,
если собираетесь вручную править двоичный формат.

## Быстрый старт

```bash
pip install -r requirements.txt

cp config.example.json config.json          # правьте под своё устройство/версию
mkdir -p work fonts
cp /path/to/base.apk work/base.apk          # ваша копия приложения
cp /path/to/NotoSans*.ttf fonts/            # любой шрифт, который вам можно использовать

python tools/extract.py                     # APK -> work/*.bundle
python tools/probe.py                       # обзор: записи шрифтов и UI-страниц

python tools/dump_strings.py --out work/strings.tsv    # выгрузить английские строки
# ...перевести, сохранить как locales/<ваш-язык>/strings.tsv...

python tools/build.py --tag my1
python tools/apksurgery.py --src work/base.apk \
    --new-bundle work/my1-data.bundle  --entry <data entry>  --dst work/my1.apk
python tools/apksurgery.py --src work/my1.apk \
    --new-bundle work/my1-index.bundle --entry <index entry> --dst work/my1-final.apk
tools/devtest.sh work/my1-final.apk my1
```

`apksurgery.py` нужно выполнить дважды — сначала data-bundle, потом
index-bundle. Подробности: [упаковка APK](docs/09-apk-packaging.md).

Без устройства: `python tests/smoke_test.py` — девять тестов на синтетическом
bundle, включая перезапись двух таблиц и тест, который демонстрирует, как
небезопасный режим замены уничтожает имя контрола.

## Структура репозитория

```
tools/
  stride_bundle.py     контейнер bundle: заголовок, таблицы записей, LZ4-поток
  stride_font.py       OfflineRasterizedSpriteFont + чтение атласа
  bundle_writer.py     перезапись обоих bundle с согласованием таблиц
  atlas_repack.py      растеризация и укладка новых глифов ниже атласа
  string_patcher.py    точная замена по varint (и небезопасные режимы — для изучения)
  build.py             весь конвейер
  extract.py           APK -> bundle
  probe.py            обзор всех записей объектов и их типов
  dump_strings.py      выгрузка переводимых строк в TSV
  apksurgery.py        замена bundle внутри APK без переподписи
  devtest.sh           установка на гарнитуру и проверка живучести
locales/
  zh-CN/               эталонный перевод (187 записей)
  _template/           заготовка для нового языка
docs/                  12 страниц: обратный инжиниринг и практические руководства
tests/                 тесты на синтетических данных
```

## Добавление своего языка

Нужен один TSV-файл и один конфиг шрифтов. См.
[docs/08-new-language.md](docs/08-new-language.md).

Кириллица, греческий и расширенная латиница работают сразу с Noto. Арабскому
и ивриту нужны предварительно сформированные битмапы (движок не делает RTL
shaping). Тайскому и индийским письменам нужен настоящий shaping — растеризация
по отдельным кодовым точкам не даст корректного текста.

## Область применения и ограничения

* Проверено на Virtual Desktop 1.34.22.0 / PICO 4 / Android 10. Номера записей
  меняются между версиями приложения — `tools/probe.py` найдёт их за вас.
* Предполагается та же сериализация Stride/Xenko. Другие движки не
  поддерживаются.
* Только текст UI. 3D-текст, рендерящийся внутри приложения, и десктопный
  сервер не покрываются.
